Initial Connect

One-time · 3 steps
  1. Open Connectors in Claude

    Go to claude.ai → Customize → Connectors → Add custom connector.

  2. Name it p2gift and paste the server URL

    Name: p2gift. Paste the server URL from the card above.

  3. Add and connect

    Click Add, then Connect, and sign in if p2gift asks. If Claude notes the values came from an external link, that is expected — confirm to continue.

After that

Use it · remove it
  1. Use it in any Claude chat

    Open a new chat, tap + → Connectors, turn on p2gift, and make your request. No need to set it up again.

  2. Remove it any time

    Go to Customize → Connectors, open p2gift, and disconnect it.
